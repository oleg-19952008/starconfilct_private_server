AccountGranter
Небольшая консольная утилита на C#/.NET 8, которая следит за коллекцией accounts в локальной MongoDB игры Star Conflict и автоматически выдаёт новым (а также недавно изменённым) аккаунтам стартовый набор ресурсов.

Скомпилированный файл называется ConsoleApp19.exe.

Что делает
Находит базу данных игры автоматически в %LOCALAPPDATA%\Targem\StarConflict\cloud\mongodb\data по файлу cosmosim_*.ns (берётся самый «свежий»), либо читает имя БД из config.txt.

Подключается к MongoDB по адресу mongodb://127.0.0.1:27017.

В бесконечном цикле раз в секунду опрашивает коллекцию accounts:

Новые аккаунты — все документы с _id > last (граница хранится в last_id.txt).

Перепроверка — в течение 90 секунд после выдачи аккаунт остаётся «на радаре», потому что Shard игры может перезаписать профиль своей копией. Если поля снова «просели» — выдача повторяется.

Выдача производится через оператор $max, поэтому значения никогда не уменьшаются — только поднимаются до нужного минимума.

Что выдаётся
Поле	Минимальное значение	Тип
tokenCredits	999 999 999	BsonInt64
vesselExpPool	999 999 999	BsonInt32
accountExpPool	10 000	BsonInt32
accountRank	15	BsonInt32
Список задаётся в массиве Grants — при необходимости легко расширяется.

Запуск
bash
# обычный режим — обрабатываются только аккаунты, появившиеся после запуска
ConsoleApp19.exe

# обработать все существующие аккаунты (начиная с самого первого _id)
ConsoleApp19.exe --all
При первом запуске без --all и без файла last_id.txt граница выставляется на текущий момент — старые аккаунты не трогаются.

Конфигурация
Если база не найдена автоматически, утилита ищет файл config.txt рядом с ConsoleApp19.exe (или в текущей рабочей папке). Формат:

txt
database_name = "cosmosim_XXXXXXX";
Ключ ищется без учёта регистра, парсер понимает строки вида ключ = "значение";.

Файлы, создаваемые во время работы
last_id.txt — _id последнего обработанного аккаунта (чтобы после перезапуска не выдавать повторно всё заново).

Сборка
Требуется .NET 8 SDK. Проект настроен на публикацию в один self-contained exe под Windows x64:

bash
dotnet publish -c Release
Готовый бинарник появится в bin/Release/net8.0/win-x64/publish/ConsoleApp19.exe — .NET-рантайм внутрь уже вшит, ничего дополнительно ставить не нужно.

Зависимость: MongoDB.Driver 2.12.4.

Как это работает (кратко)
FindDbInAppData() — сканирует папку данных MongoDB игры и по самому свежему cosmosim_*.ns вычисляет имя базы.

BuildUpdate() — собирает UpdateDefinition из массива Grants, применяя $max для каждого поля.

NeedsGrant(doc) — проверяет, нужно ли вообще что-то выдавать (поля отсутствуют / не число / меньше целевого).

Главный цикл:

выбирает новые документы (_id > last), применяет апдейт, ставит их в словарь watch и сохраняет новую границу в last_id.txt;

раз в тик обходит watch, и если Shard «откатил» поля — перевыдаёт.

Ограничения и замечания
Утилита предназначена для локальной одиночной игры и работы с локальной MongoDB.

Ошибки цикла ловятся, лог пишется в консоль, после ошибки — пауза 2 секунды.

Одновременно должен быть запущен только один экземпляр, иначе last_id.txt будет перезаписываться наперегонки.

Имя проекта в .csproj (ConsoleApp19) не менялось — если хотите аккуратный бинарник с другим именем, задайте <AssemblyName>AccountGranter</AssemblyName> в PropertyGroup.
